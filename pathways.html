Intermediate

Outcome: Gain Hands-on Experience

The Intermediate level has moved beyond first contact, having now experimented with Copilot in different situations and surfaces. Proficient

Outcome: Prove Your Expertise

The Proficient level represents a developer who can practically apply GitHub Copilot across typical scenarios, demonstrated through consistent hands-on usage across multiple repositories and extended periods. A Proficient user can use many web and IDE features, select appropriate models, and apply customizations to tailor Copilot for specific project needs. They have experimented with extended features and are aware of extensibility and integration options.

Learn GitHub Learn modules

  • ModuleBuilding applications with GitHub Copilot agent mode (Est. completion time: 45 min)
  • ModuleIntroduction to MCP Server (Est. completion time: 35 min)
  • ModuleUsing advanced GitHub Copilot features (Est. completion time: 22 min)

Advanced

Outcome: Design and govern agentic workflows

The Advanced level represents a practitioner who can design, orchestrate, and operate agentic AI workflows across the software development lifecycle. They define agent roles, boundaries, and success criteria; integrate tools and execution environments; coordinate multiple agents; manage memory, state, and evaluation; and apply governance, least-privilege access, human oversight, and operational safeguards. They can use these capabilities to advance their own work or support customer outcomes.
