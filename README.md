# IBM x GitHub Copilot Learning Journey

Public example microsite presenting self-paced GitHub Copilot learning pathways, partner delivery credentials, live training, peer showcases, and FAQs.

## GitHub Pages

The site is served from the repository root. The landing page is `index.html`, with entry points for the user journey ("Use & build with Copilot") and sales journey ("Sell GitHub Copilot"). Everyone, including sellers, can explore both journeys.

`pathways.html` contains learning levels, course links, certifications, and Partner Delivery Credentials. `sales.html` contains Partner Guides, Sales Credentials (Sales motion, Platform, Copilot), Tech Forum, and PKO Session Recordings. Live training, peer showcases, and FAQs are shared on the landing page.

## Notes

- Course links and pathway assignments should be reviewed with the IBM and GitHub partner teams before production use.
- Live training dates, registration links, and showcase contributions will appear as confirmed.
- Partner Delivery Credential courses require access to the GitHub Partner Portal.
- Seller resource details and external links are placeholders pending confirmation. Sales Credentials are distinct from certifications and Partner Delivery Credentials.
