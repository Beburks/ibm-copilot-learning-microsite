# IBM x GitHub Copilot Learning Journey

Public example microsite presenting self-paced GitHub Copilot learning pathways, partner delivery credentials, live training, peer showcases, and FAQs.

## GitHub Pages

The site is served from the repository root. The landing page is `index.html`, with entry points for the user journey ("Use & build with Copilot") and sales journey ("Sell GitHub Copilot"). Everyone, including sellers, can explore both journeys.

`pathways.html` contains learning levels, course links, certifications, and Partner Delivery Credentials. `sales.html` contains Partner Guides, featured Sales Motion and Copilot Sales Credentials, a link to the full Sales Credentials catalog, Tech Forum, and PKO Session Recordings. Live training, peer showcases, and FAQs are shared on the landing page.

## Notes

- Course links and pathway assignments should be reviewed with the IBM and GitHub partner teams before production use.
- Live training dates, registration links, and showcase contributions will appear as confirmed.
- Partner Delivery Credential courses require access to the GitHub Partner Portal.
- Featured GitHub Sales Motion and GitHub Copilot Sales Credential cards include user-provided descriptions, Partner Portal links, and 90-minute estimated completion times. The featured credentials are relevant to GitHub Copilot but are not an exhaustive list; a separate box links to the full Sales Credentials catalog. Partner Portal access is required. Other seller resources remain placeholders. Sales Credentials are distinct from certifications and Partner Delivery Credentials.
- Module and skill completion estimates use `(Est. completion time: ... min)` and are sourced from official course descriptions, duration metadata, or GitHub Skills READMEs. Hours are converted to minutes; upper bounds and ranges are preserved (for example, `<60 min` or `90–120 min`). Times are omitted when not listed by the source.
